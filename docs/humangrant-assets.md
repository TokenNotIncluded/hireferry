# 人类辅助登录界面与素材

聘渡使用「人类辅助登录」作为中文入口名称，英文短名称为 **Human Login**。AI 发起申请，用户登录并明确选择权限，AI 再获得独立访问凭据。底层协议名称、API 路径和 AI 接入说明中的技术标识仍为 HumanGrant。

## 新设计

图形由人形和授权确认标记组成，以内联 SVG 绘制。人物和确认标记使用主题中的前景色，与按钮背景保持对比；避免强调色人物落在同色按钮背景上、只剩一个勾的情况。图标、按钮和页面卡片共同使用网站已有的主题变量，适配暖橙深色主题及其他可选配色。

入口名称、介绍页标题、返回入口及未开放状态均随界面语言切换。按钮使用真实 HTML 文字，支持键盘操作、缩放和屏幕阅读器；不再将固定英文名称作为图片或不可翻译文字嵌入页面。

| 实现 | 用途 |
| --- | --- |
| `static/humangrant-ui.js` | 本地化文字、内联图标、介绍页、审核页和授权管理 |
| `static/app.css` | 登录入口与 HumanGrant 页面的主题样式、卡片及移动端布局 |
| `static/humangrant/` | 独立 SVG 素材，供展示和复用 |
| `tests/humangrant-ui.test.mjs` | 中英文入口与未开放状态，以及授权行为回归检查 |

图形为聘渡绘制，随本仓库许可发布。装饰图形不承载权限或状态信息；权限、状态和操作均有明确的文字说明。

## 页面

- `/login`：显示「人类辅助登录 / Human Login」入口，与其他登录方式使用一致的字号、图标和按钮层级。关闭服务配置后，不显示这个入口。
- `/humangrant`：以简短标题和三步流程说明 AI 申请、用户确认、AI 继续；将复制说明的主操作放在靠前位置。完整接入说明及本站确认链接入口都可在页面中访问。
- `/human/{link}`：显示服务、申请者标识、用途、当前账户、具体权限、资源和到期时间。权限默认全部不选。用户另需勾选明确同意，才能提交允许操作。
- `/app?tab=agents`：在 AI 连接页显示人类辅助登录的授权、权限、创建时间、到期时间与撤销入口。

页面使用网站现有主题设置，支持浅色和深色模式。小屏幕下，步骤与操作卡按阅读顺序排列，避免大型装饰图形将复制和确认操作挤到很远的位置。键盘焦点有可见样式，权限选择和状态均不只依靠颜色表达。

完成后的确认页显示实际批准范围和授权截止时间，并按当前授权状态说明是否可继续使用。撤销、到期或权限减少后，原批准范围明确标为历史记录；未获批准的申请权限不进入这份清单。

## 登录恢复

用户从确认页进入邮箱或 Google 登录后，页面会恢复同一申请。浏览器只在当前标签页保存一个严格匹配 `/human/{link}` 的同源路径；保存记录一小时后失效。外部 URL、查询串、片段、短链接和编码路径不会作为登录后目标。

这份浏览器记录不提供任何权限。确认页和提交操作仍由服务器重新检查当前登录、申请状态和账户权限。切换账户后，旧确认凭据不能使用。

## 检查

```sh
node --input-type=module --check < static/humangrant-ui.js
node --input-type=module --check < static/app.js
node tests/humangrant-ui.test.mjs
node tests/service-ui.test.mjs
```

专项界面测试覆盖中英文入口、介绍页标题、未开放状态、链接恢复、文本转义、明确选择权限、确认凭据、账户不匹配、申请结束和授权撤销。它们不替代真实签名、账户登录和服务器权限测试。
