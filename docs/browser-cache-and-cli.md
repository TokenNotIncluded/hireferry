# CLI 页面与浏览器缓存

更新：2026-10-22。

## 页面与交互

`/cli` 使用双栏介绍与终端演示，窄屏改为单栏。终端从 `> hfy_` 开始逐字展示设备码登录、身份查询和权限查询；命令使用当前部署配置中的服务地址。页面明确标注演示，不显示虚构的账户或登录结果。

安装区域提供 macOS / Linux、Windows 两个键盘可操作的标签页。复制按钮始终复制完整命令，成功后显示勾号和「已复制」，随后恢复；剪贴板不可用时尝试兼容方式，仍失败则提示手动复制。命令换行展示，不依赖横向滚动。

动画只使用一个计时器，页面隐藏、终端离开可见区域或用户暂停时停止。系统启用减少动态效果时，显示完整示例并关闭光标闪烁。

## 缓存与更新

| 内容 | 保存方式 | 失效与刷新 |
| --- | --- | --- |
| 公开站点配置 | `localStorage`，键为 `hireferry-public-config-v1` | schema 1、最多 24 小时；损坏、超大或无效记录丢弃 |
| JS、CSS、字体、图片等静态文件 | `/static/<发布内容摘要>/...`，浏览器 HTTP 缓存 | `public, max-age=31536000, immutable`；内容变化生成新路径 |
| HTML、旧的无版本静态路径 | 浏览器 HTTP 缓存并重验证 | `no-cache`，匹配 ETag 返回无正文的 304 |
| 会话、账户、消息、令牌、支付结果 | 不进入新增的持久缓存 | 保持既有实时读取与服务端授权 |

公开配置只保存明确允许的字段，包括站点名称、公开服务地址、联系邮箱、登录方式开关、CLI 发布源、公开费用与功能限制。浏览器存储被禁用或空间不足时退回内存，不影响正常使用。

首页、CLI、联系页和退款说明页可直接使用有效快照显示正文，然后在后台重验证。首次访问没有快照时，公开页面只等待配置，不等待会话接口。进入需要身份的页面时，持久快照不能代替实时配置与会话检查。账户切换和退出使相关在途读取失效，迟到结果不能恢复旧身份或覆盖新导航。

后台返回相同内容时不重新挂载页面；变化内容按稳定标识比较，最多对 12 处文本播放「删除线并淡出（200 ms）→ 替换 → 淡入（180 ms）」。表单、正在聚焦或选择的文字不播放这段效果，减少动态效果或后台标签页立即更新。平台选择、展开状态和现有表单输入由挂载逻辑保留。

公开配置请求失败时保留已经显示的快照。页面再次变为可见或网络恢复时再次检查。该行为不提供完整离线应用能力：没有加载过的代码和需要实时账户数据的页面仍依赖网络。

静态文件使用同一发布摘要，相对模块导入继承对应版本路径。旧版本或不存在的资源返回 404，不把新文件放到旧的 immutable 地址下。gzip 压缩只用于静态响应，私有 API 和授权页面保留原有 `no-store` 行为。

## 验证与复现

无需安装前端依赖的回归测试：

```sh
for suite in tests/*.test.mjs; do node "$suite"; done
cargo test --locked --test static_assets --test cli_distribution
```

真实浏览器检查使用合成公开配置和访客会话，并拒绝访问外部服务：

```sh
HFY_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs \
node tests/cli-polish-browser.mjs
```

脚本检查打字与暂停、离屏停止、键盘平台切换、完整命令复制、缓存先显示后刷新、内容更新动画，以及明暗主题下 1440、390、320 px 的布局和减少动态效果。首屏检查通过主动挂起网络响应、等待内容出现后再释放响应验证，不以机器速度相关的固定毫秒阈值判定成败。

`HFY_BROWSER_EXECUTABLE` 可指定 Chromium，`HFY_BROWSER_ARGS_MODULE` 可指定浏览器运行环境提供的参数模块；设置 `HFY_BROWSER_SCREENSHOTS` 时保存本地验证截图。该脚本已加入 CI 既有浏览器步骤。

脚本报告的首屏毫秒数仅是本地合成服务下从导航开始到正文就绪的观察值，不代表生产网络、真实用户设备或后端容量。
