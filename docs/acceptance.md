## 3. 外部服务与生产部署：待部署方端到端验收

以下项目需要真实凭证、域名、账户或设备，目前未据本地测试声称通过。

| 外部依赖 | 上线前验收 |
| --- | --- |
| Google OAuth | 真实 client ID/secret、授权回跳。示例回调 https://hireferry.lmm.best/auth/google/callback，替换实际域名；同名邮箱不自动合并 |
| SMTP | 真实 TLS 邮件投递、实际收件、8 位验证码、过期与重新申请 |
| 实体 Passkey | 实际 HTTPS 来源/RP ID，首把与备用密钥、退出再登录、最近认证和最后一把保护 |

| Waffo Pancake | merchant/store/product、RSA 密钥、CNY/税类、test/prod、托管收银台和 order.completed 回调 |
| 外部 AI 客户端 | 实际客户端手动 Bearer MCP 连接、消息游标持久化/重试、相应身份工具调用、撤销后的拒绝 |
| 外部寻找/联系 | 另行配置并授权的搜索或邮件服务；本应用只记录委托/同意/实际进展，不内置 LLM、爬虫、第三方求职平台接入或自动投递 |
| Linux 部署 | 域名 HTTPS、代理、时钟、文件权限、systemd 重启、在线备份与恢复演练 |
| 交付 | 发布包排除密钥、SQLite、个人令牌、引导口令和 QA 资料；核对第三方版权说明 |

个人和管理员 AI 令牌各自 30 天有效、最多 10 个有效令牌，明文仅显示一次。管理员令牌仅由真实管理员 Cookie 在最近 Passkey 认证后签发；不能用 Bearer 扩增凭证，也不能操作 Passkey 或系统配置。用户/管理员远程 MCP 各 26 工具，浏览器 WebMCP 按角色提供对应能力，均复用当前授权。

支付由验签回调决定，不由跳转页面、聊天或 AI 自行确认。异常到账 paid_needs_review 不直接授权；自动退款与争议处理未实现，需管理员通过商户后台核对。平台管理员可以全知业务记录，但不能伪造支付或替求职者扩大外部同意。

所有站点/邮件/支付/Google 配置均为 TOML，网站没有系统设置页。示例域名 https://hireferry.lmm.best、条款 /terms、隐私 /privacy 应在实际部署时确认正确并替换必要内容。
