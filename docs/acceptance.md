## 2. 页面切换与输入隔离

切页立即呈现对应内容区的静态占位布局；全站页头、侧栏、底栏和不变的导航节点原位更新。同页刷新保留现有内容，并标记局部忙碌状态。可选 AI 工具资格查询在页面挂载后完成，不阻塞页面内容。

只有当前渲染请求能够提交页面、身份和 AI 资格；旧请求失败不能覆盖新页面。换会话时重建消息区域，旧草稿不会被带给另一位收件人；会话列表和全站导航仍保留。候选人详情、备注及批量选择也按资源和查询代次隔离。关闭弹窗只向仍存在的原按钮恢复焦点，普通切页不会被旧弹窗按钮抢走焦点。

## 3. 计费、币种与账号权限

发布与描述修改分别支持 `salary_percent`、`fixed` 和 `free`；比例、按币种固定金额、开通费用、编辑次数及 AI 薪资门槛来自 TOML。所有金额按整数最小货币单位处理；API 为兼容保留 `_cents` 字段名，配合记录的 `currency` 和 `currency_decimals` 使用。日元/韩元为零位，已实现的其他币种为两位；不会统一乘除 100，也不进行隐式汇率换算。

新岗位保存原币种、编辑费用和次数、AI 门槛。站点以后改价或换默认币种，不重标旧岗位或订单。旧数据按其历史 CNY 语义迁移。不同币种的薪资不直接比较，收入/退款独立分组。网站启用币种与支付网关可用币种分别配置；创建订单和结账都会检查网关币种，历史已验证回调仍按订单原始数据入账。

封禁和恢复需要管理员权限、CSRF 与操作原因，并写审计。封禁撤销现有登录、个人 AI 令牌和待使用验证码；恢复不会复活旧凭据。Google 授权流程会检查账户访问代次。普通 API、MCP、匹配、聊天和出站事件按当前账号状态复查；封禁后的迟到投递响应不能重新排入重试队列。已发出的网络请求无法被收回。

招聘人数可免费不限次数修改，0 暂停新介绍，既有会话保留。首次删除可恢复一次；恢复后的下一次删除为永久删除。版本校验拒绝过期写入，永久删除清除内容但保留账务关联。已失效的付款链接不再暴露，迟到真实到账进入人工核对，不会复活岗位。

远程 MCP 当前为 32 个成员工具和 32 个管理员工具，包含只读站点配置与管理员批量介绍。管理凭据与个人凭据隔离，工具发现不代替业务授权。

## 5. 本地运行与浏览器边界

本地独立 QA 数据库使用 42 个合成账户、3 个不同币种岗位及对应订单/账本。最终本地二进制通过生产/开发两份模板的 check-config。HTTP 冒烟检查覆盖健康接口、首页、支付返回、退款、联系、条款、隐私与新增静态模块；四份中英文政策 API 返回成功，内容采用测试配置的 USD、JPY、7.5% 发布费与 0.5% 修改费。在线备份的 `integrity_check` 为 `ok`，外键检查无错误；恢复到独立副本后服务健康检查为 204，账户/岗位/订单/账本数量一致。这些不证明真实 Google、邮件或网关已经接通。

**本轮没有完成新版桌面/手机截图和实际浏览器操作验收。** 云端浏览器无法连接本地服务，随后访问被浏览器安全策略阻止；没有通过其他浏览器控制路径绕过，也没有把旧截图计入本轮证据。仍需检查真实慢网占位、焦点与滚动、手机布局及浅色/深色视觉效果。

## 7. 复现

```sh
cargo fmt --all -- --check
cargo test --locked -j 1
cargo test --locked -j 1 --test workbench -- --ignored --nocapture
for asset in static/*.js static/runtime/*.js; do
  node --input-type=module --check < "$asset" || exit 1
done
for suite in tests/*.test.mjs; do node "$suite" || exit 1; done
cargo build --locked --release
./target/release/hireferry --config config.example.toml check-config
```

本轮本地因磁盘限制使用离线缓存及专用临时构建目录，Rust 套件顺序运行；CI 使用标准环境完整执行。接口与配置细节见 [API](api.md)、[岗位](jobs.md)、[支付](payments.md)、[认证](auth.md)、[Webhook](webhooks.md)、[政策配置](legal-policies.md) 和 [部署交接](deployment-handoff.md)。
