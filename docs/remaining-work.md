## 尚未合入 main 的要求

- [ ] **大规模匹配工作台。** 以岗位为入口，服务端搜索并分页返回候选人和匹配；独立详情面板、批量处理和精确筛选。现有管理员匹配列表最多返回 200 条，前端仍是四列看板。使用 100,000 名求职者、1,000 家招聘方的合成数据做查询、操作和权限测试。
- [ ] **招聘人数免费调整。** 岗位人数可反复修改，不消耗三次收费 JD 修改额度；人数为 `0` 时停止新的匹配，已有会话保留。网页、MCP、服务端及事件通知规则一致。
- [ ] **岗位删除与一次恢复机会。** 首次删除可从回收站恢复一次，也可主动永久删除；恢复后再次删除是永久删除。重复请求不能意外二次删除。删除免费，留存必要的财务流水。对现存匹配和付款回调进行回归测试。
- [ ] **暗色模式。** 系统／浅色／深色三档；保存用户选择。覆盖登录、聊天、招聘、管理、图表、弹窗和粒子背景，检查文字对比度和手机端。
- [ ] **用户自定义 Webhook。** 用户可登记事件接收地址和订阅范围，支持签名、启停、投递历史、失败重试及目标地址安全限制；仅发送该用户有权查看的事件，撤权后停止投递。
- [ ] **Waffo 退款事件。** 除当前的 `order.completed` 外，补齐 `refund.succeeded` 和 `refund.failed` 的验签、去重、订单及流水状态与测试。不能通过浏览器返回参数确认付款或退款。
- [ ] **完整的部署页面。** 接入 `/billing/return`、`/refunds`、`/contact`。保留现有 `/terms`、`/privacy` 和 `/auth/google/callback`；Waffo 接收端继续为 `POST /api/webhooks/waffo`。线上域名统一配置为 `https://hireferry.lmm.best`，客服和邮件回复地址为 `support@lmm.best`。
- [ ] **文案复查。** 按 `lieflat-less-ai-tone/SKILL.md` 的明确命中规则逐项检查当前中英文界面，保持金额、权限条件、取消和删除后果完全准确，不新增未经验证的承诺。
