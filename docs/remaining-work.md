## 明确边界

币种支持以已实现的精度表及支付渠道能力为限；不会向未知币种猜测精度或自动换汇。商户可在网关配置中进一步缩小币种集合。最近订单/匹配等记录使用配置容量，完整历史分页仍是后续改进。Webhook 历史有配置的保留和容量限制。

Stripe 退款及争议事件尚未自动同步，需商户人工核对；网站不直接发起退款。外部 AI 招聘渠道不因 MCP 接口存在而自动接入。法律文档中的保留、退款和响应期限是运营承诺，不会自动创建清理或退款任务。

源码、Linux 发布包、CI 和云盘归档属于本轮交付；真实服务凭据、运行配置及 QA 数据库不进入归档。可构建、测试通过不等于已完成收费运营验收。
