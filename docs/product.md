# 产品与业务规则

[项目首页](../README.md) · [文档导航](README.md) · [API 与 MCP](api.md)

聘渡由人类 HR 与已授权 AI 协作完成招聘匹配。求职者提交资料与求职委托，招聘方提交岗位，双方分别与平台沟通。平台建立具体介绍后，双方获得对应资料与新的匹配会话。

## 服务流程与隐私

1. 使用 Google 或邮箱验证码登录，选择求职者或招聘方身份。
2. 求职者填写头像、联系邮箱和 Markdown 简历，提交目标行业、岗位、薪资、地点及偏好。招聘方完成开通并发布岗位。
3. 双方各自与平台私聊。平台 HR 和获准访问的 AI 整理需求、筛选候选人。
4. 平台将有效求职委托介绍给发布订单已完成且招聘人数大于 0 的岗位。
5. 每次匹配开启独立会话，双方查看对应资料、岗位和联系邮箱，并跟进面试与录用。

平台可查看业务资料与沟通记录。其他用户仅能访问已获介绍的具体对象，没有公开简历或岗位目录。各自与平台的私聊留在原会话中，不会复制到匹配会话。

`public_email` 是保留兼容名称的联系邮箱字段，供平台及匹配对象使用。登录邮箱仅本人、获准读取本人资料的 AI 和平台管理员可见。旧 `visible` 字段不授予公开访问权。

### 匹配访问与撤回

| 变化 | 结果 |
| --- | --- |
| 匹配改为 `declined` | 撤销普通用户对该匹配资料与会话的访问 |
| 删除岗位或封禁任一方 | 隐藏相关匹配资料与会话 |
| 恢复岗位 | 按当前权限重新检查原匹配历史 |
| 招聘人数设为 0 或关闭岗位 | 暂停新介绍，已有匹配会话可继续 |
| 会话归档 | 保留管理员读取权，所有身份均停止发送，`writable: false` |

## 工作台

| 角色 | 工作内容 |
| --- | --- |
| 求职者 | 资料、求职委托、外部寻找进展、平台私聊、匹配会话与未读提醒 |
| 招聘方 | 多岗位、Markdown JD、招聘人数、回收站、支付、订单与匹配对象 |
| 平台管理员 | 用户及岗位管理、封禁、候选筛选、批量介绍、跟进、会话、订单与审计 |

管理员收入图表按币种分别统计原实收、已退款和净收入，支持日期区间与历史累计，正式和测试流水分开。

网页支持简体中文和英文，以及浅色、深色和跟随系统的外观。浏览器保存语言与外观偏好。系统设置使用 TOML，修改后重启服务。

### 平台匹配工作台

管理员先选择当前可招聘的岗位，再按关键词、行业、目标岗位、地点及同币种薪资范围筛选候选人。列表加载摘要，完整简历和单条匹配按需读取。

列表使用游标分页。`[limits].workbench_page_size` 默认 25，单次范围为 1–100。已有有效匹配的候选人不重复进入待选名单，已终止匹配须再次通过业务检查才能恢复。跟进列表支持搜索、阶段筛选及最近更新时间排序。

搜索仅向管理员和独立管理员 AI 开放。搜索结果不会自动建立匹配或扩大求职者授权。SQLite 使用查询索引及 FTS5 trigram 搜索，较短关键词使用受筛选条件约束的字面匹配。

完整请求和分页规则见 [工作台 API](api.md#岗位中心匹配工作台)，规模验证见 [验收记录](acceptance.md)。

## 求职委托与外部寻找

求职者开启 `active` 委托后，平台可围绕需求进行站内匹配。外部联系另需本人开启 `allow_external`，系统记录授权时间及是否通过 AI 提交。

求职者可以暂停或关闭委托，也可以撤回外部联系授权。管理员不能代为创建、扩大或重新激活这些同意。暂停或撤权后，只能关闭已有外部进展，不能登记新的外部联系活动。

平台记录发现机会、已联系、收到回复、面试、录用与结束等实际进展。AI 模型、第三方搜索和外部邮件由独立服务提供，并使用相应账号与授权。聘渡提供业务记录、API 和 MCP 接口，来源 URL 本身不会触发外发操作。

## 收费与币种

求职者免费。招聘方按操作计费。以下为配置模板的 CNY 示例：

| 操作 | 模板默认值 | 月薪底薪 ¥3,000 的示例 |
| --- | --- | --- |
| 招聘方开通 | 一次性 ¥100 | ¥100 |
| 发布岗位 | 底薪的 10% | ¥300 |
| 修改 JD | 原底薪的 1%，最多 3 次 | 每次 ¥30 |
| 修改招聘人数 | 免费，不限次数 | 设为 0 暂停新介绍 |
| 删除、一次恢复、永久删除 | 免费 | 不改变 JD 修改次数 |

实际价格由 TOML 决定。`[pricing].currency` 设置默认币种，`allowed_currencies` 设置可选币种。发布和 JD 修改分别支持 `salary_percent`、`fixed` 和 `free`。开通费为零时直接开通。

### 金额和岗位条款

- 底薪不含奖金、提成或补贴。岗位创建后标题、币种和底薪固定。
- 金额使用该币种的整数最小单位。USD 12.34 保存为 1234，JPY 1234 同样保存为 1234。兼容字段后缀 `_cents` 不代表统一两位小数。
- 新增币种须显式配置固定价格和 AI 薪资门槛。系统不推算汇率，薪资筛选仅比较相同币种，收入也按币种分开统计。
- 岗位保存创建时的编辑收费方式、费率、固定金额、可编辑次数和 AI 薪资门槛。配置变更适用于新岗位。
- 按比例修改费依据原底薪计算，招聘人数不影响费用。

### 支付与退款

Stripe 和 Waffo Pancake 提供托管收银台。付费操作在验签到账后通过 SQLite 事务生效。免费操作立即生效，生成零金额已完成订单，不调用网关或写现金账本。

支付返回页读取当前账户的订单状态，跳转本身不确认付款。Waffo 支持付款成功、退款成功和退款失败通知。成功退款按退款发生日期减少净收入，失败退款仅记录结果。

部分退款保留服务权益。全额开通退款撤回开通权益，全额发布退款关闭相应岗位。JD 修改退款不回滚文本或恢复修改次数。退款由商户后台发起，本站不主动发起退款，Stripe 退款与争议通知尚未实现。

网关支持币种、独立开通价格、Waffo 区域与测试模式、签名及回调规则见 [支付说明](payments.md)。

## 优惠码与申请

招聘方在「招聘优惠」提交申请、查看审批结果或输入已有优惠码。管理员在总控台审核申请或创建优惠码。

免费开通默认附带 1 次，可关闭。发布优惠次数单独设置，减免 100% 即免费发布。两类次数按整个优惠码累计。免费操作成功时扣次，付费优惠订单先预占次数，取消或到期后释放。

详情见 [优惠码说明](promo-codes.md)。

## 招聘人数与回收站

`headcount` 是人工维护的计划招聘人数，默认 1，范围为 0 到 `[limits].max_job_headcount`，模板上限为 1,000,000。已开通且未封禁的招聘方可免费修改自己草稿或已发布岗位的人数。

设为 0 会暂停新介绍，岗位仍保持 `published`。改为正数后恢复这类已发布岗位的招聘。匹配、面试和入职不自动扣减人数，正数也不限制匹配总数。已有匹配会话可继续。

第一次普通删除进入回收站，可免费恢复一次。恢复后再次删除或直接选择永久删除，会清除岗位标题、JD 和关联订单内容快照，取消待付款的相关订单，并保留必要账务及审计记录。管理员删除直接执行永久删除。

删除和恢复必须携带当前 `expected_version`。重复删除仍处于回收站的岗位不增加删除次数。恢复不产生新费用，也不会恢复已退款的权益。原开通及发布权益失效时，岗位恢复为 `closed`，人数为 0。

状态转换、竞态和付款约束见 [岗位管理](jobs.md)。

### AI 使用资格

求职者选择身份后可免费连接 AI。招聘方需已开通，并持有至少一个发布订单已完成、状态为 `published`、底薪达到该岗位保存的币种薪资门槛的岗位。免费发布的已完成订单也符合发布条件。

招聘人数为 0 不影响其余条件已满足的 AI 资格。关闭或删除最后一个符合条件的岗位后，既有招聘方 AI 凭据也会受到限制。服务端在每次业务请求重新检查当前权限。

管理员使用 Passkey 会话签发独立管理员 AI 凭据。HumanGrant 仅提供获准的普通用户业务权限。所有 AI 写入沿用服务端业务校验并记录身份。

### 消息与保留策略

网页提供快速反馈入口，源码版 `hfy` 支持提交，管理员可用 CLI 或 MCP 分页查看及标记处理。`[feedback]` 配置保留期限、容量和提交频率，模板默认保留 90 天、最多 5000 条。过期身份数据由 `[maintenance]` 定时清理。安装和业务数据留存范围见[反馈与增长控制](feedback-and-retention.md)。

AI 可通过 `get_updates` 保存 `next_cursor` 并继续读取增量消息。`has_more` 为真时继续分页，否则遵守 `poll_after_ms`。重试发送同一条消息时复用 `client_id`，避免重复写入。

近期列表和分页上限配置在 `[limits]`。Webhook 的端点数、队列、尝试次数和保留期配置在 `[webhooks]`。模板默认成功及取消记录保留 30 天，失败记录保留 90 天，具体执行规则见 [Webhook 配置](webhooks.md#6-系统-toml-限制与保留)。

## 公开政策

服务条款与隐私政策使用独立的中英文 Markdown 模板。`[legal.values]` 设置运营方、版本、生效日期、退款窗口及保留期限，`[legal.document_files]` 可提供完整替代文档。

费用、币种、金额精度、修改次数和 AI 门槛从业务配置生成。政策变量不能覆盖业务价格，旧岗位保留原条款。政策中约定的退款、注销及保留职责需要相应运营流程落实，设置文本不会自动执行这些动作。

详情见 [政策配置](legal-policies.md)。
